# 04 · Mapa de stakeholders del ecosistema territorial

> **Estado: en preparación.** Falta el gráfico de actores (insumo pendiente).

## Objetivo
Representar el ecosistema con el que se articula el trabajo de datos y monitoreo del programa territorial:
quién produce la información, quién la valida, quién la usa para decidir y con qué autoridad.

## Actores identificados

| Actor | Rol en el sistema de información |
|---|---|
| **Dirección Regional de Educación de Áncash (DRE Áncash)** | Articulación regional; alineamiento de la información y de los resultados educativos. |
| **UGEL Huari** | Coordinación directa para el recojo de información y la retroalimentación de resultados. |
| **UGEL Huarmey** | Coordinación con especialistas para la validación y el recojo de datos. |
| **UGEL Recuay** | Coordinación con especialistas para la validación y el recojo de datos. |
| **UGEL Bolognesi** | Trabajo articulado dentro del territorio del programa. |
| **Instituciones educativas y docentes** | Fuente primaria del dato y usuarios de la retroalimentación. |
| **Familias y estudiantes** | Participantes y fuente de información directa (vía instrumentos). |
| **Equipo territorial (coordinación, facilitadores)** | Recojo en campo, verificación y uso operativo de los tableros. |
